# Marcela Maestrelli | Advocacia Estratégica

Create a premium, modern and conversion-focused landing page for a fictional Brazilian lawyer named **Marcela Maestrelli**, specialized in **Family Law and Succession Law**.

This is a portfolio/demo project. Marcela Maestrelli is fictional, and all contact information, OAB number and testimonials must be clearly demonstrative.

## GOAL

Build a polished landing page that looks like a real high-end law professional's website, designed primarily to generate consultation leads through WhatsApp.

The site should communicate:
**trust, sophistication, professionalism, clarity and human approach.**

Avoid the generic "law firm template" aesthetic.

## BRAND

Name: **Marcela Maestrelli**
Profession: Advogada
Specialization: Direito de Família e Sucessões
Location: São Paulo, SP
Service: Presencial e online
OAB: OAB/SP 000.000 
Phone: (11) 99999-0000
Email: [contato@marcelamaestrelli.adv.br](mailto:contato@marcelamaestrelli.adv.br) 
Instagram: @marcelamaestrelli.adv

Tagline:
**"Estratégia jurídica para decisões que importam."**

All visible website copy must be written in **Brazilian Portuguese**.

## VISUAL DIRECTION

Create an editorial, luxurious and minimalist aesthetic inspired by premium personal brands, architecture and modern fashion websites.

Color palette:

* Ivory / warm off-white background
* Charcoal / near-black typography
* Soft beige secondary backgrounds
* Champagne/gold accents used sparingly

Typography:

* Elegant serif font for large headings
* Modern clean sans-serif for body text and navigation

Use generous whitespace, refined grids, subtle borders, soft shadows and restrained rounded corners.

Use realistic, elegant professional photography of a female Brazilian lawyer. Avoid cliché stock photos, gavels, scales, courthouse columns or overly corporate imagery.

Animations should be subtle: fade-in, slight movement and smooth hover transitions. Never over-animate.

## IMPORTANT

Do not create a dashboard, login, blog or unnecessary pages.

Do not use generic blue law-firm colors.

Do not use gavels, scales, courthouse columns or cliché legal imagery.

Do not invent awards, statistics, clients, case results, years of experience or professional credentials.

Prioritize **visual hierarchy, typography, photography, whitespace and conversion**.

The final result should look like a premium website that a real São Paulo lawyer could use professionally, not like an AI-generated template.

Build the complete functional landing page, not just a visual mockup.
